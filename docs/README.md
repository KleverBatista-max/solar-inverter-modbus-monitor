# Inverter documentation

Documents for the "SPI 4–6.5K UP" hybrid solar storage inverter family (rebranded units sold under many names), shared so owners of similar inverters can find them — the originals are hard to find outside China.

- `modbus_register_table_V2.00.1_EN.pdf` — Modbus monitoring protocol register address table (English)
- `modbus_register_table_V2.00.1_ZH.pdf` — same table, original Chinese
- `SPI-4-6.5K-UP_inverter_manual_V1.1.pdf` — user manual

Obtained from the manufacturer's supplier, who confirmed the documents are publicly distributed. If you are the rights holder and want them removed, open an issue.
